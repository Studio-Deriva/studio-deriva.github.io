Tags

Every finding in a modscan report has a tag, like WEBHOOK or CHAINDROP, and a weight. Here is what each one means, how much it counts, and how to tell whether a mod is dangerous.

How a score is made

score = strong tags + signals (at most 30), up to 100

Strong

Strong tags count in full

Indicators that normal mods almost never have: a webhook, a stealer chain, a disguised executable. One is often enough for HIGH.

Signal

Signals add up to 30 at most

Single behaviours that plenty of normal mods have: network, reflection, starting a program. However many there are, they never make a file HIGH on their own.

LOW · 0–14

Nothing suspicious found. Not a guarantee: static analysis cannot see everything.

MEDIUM · 15–39

Something worth a look. Often signals that a normal mod has too; read the tags.

HIGH · 40+

At least one strong indicator or a chain. Do not launch it until you know why.

Cannot be judged

The code the file runs is not in the file: downloaded or decrypted later, unreadable classes, or another archive format. No score can clear it.

Files verified by Modrinth are left out of the result. Only SIGNATURE, IOC and INDEXPATH are still checked on them.

Is this mod dangerous?

  1. HIGH with a "looks like" lineIf the report says it looks like a stealer, a dropper, a loader or a hidden payload, or shows SIGNATURE or IOC: do not launch it, delete it, and tell us on Discord.
  2. HIGH from CHAINDROP on a well-known modUpdaters and installers really download and run programs. Download the mod again from its official page and scan that copy: if it is verified by Modrinth, it drops out of the result.
  3. MEDIUM made only of signalsNET, REFLECT, EXEC, NATIVE, DYNLOAD and similar are everyday behaviour. Check where you got the file rather than the score.
  4. Cannot be judgedmodscan cannot see the code that will run. Launch it only if you trust whoever made it.
  5. LOWNothing suspicious was found. Getting mods from Modrinth or the author's page is still the best protection.

Real mods that trigger strong tags

Distant Horizons' updater and the ffmpeg installers of FancyMenu and Almanac get CHAINDROP, because they really download and run a program. Xaero's updater gets CHAINUPDATE. Essential's loader gets CHAINLOAD and is "cannot be judged". The official copies of these mods are verified by Modrinth, so they are left out of the result.

Known threats

Matches with known malware. Checked even on files verified by Modrinth.

SIGNATURE+100Strong

Known malware family

The file matches a malware family in the modscan signature feed. Treat it as malicious.

IOC+100Strong

On the IOC list

The file's hash, its content or one of its strings is on the indicator list you loaded with "IOC list".

Stealing accounts and data

What stealers go after: the Minecraft session, Discord, browsers, wallets.

SESSTOKEN+30Signal

Reads the Minecraft session token

The token is the key to your Minecraft account. Account switchers and skin tools read it too; together with the network in the same class it becomes CHAINSTEAL.

DCTOKEN+40Strong

Discord token harvesting pattern

Looks for the place where Discord keeps its login token, the way token stealers do.

BROWSER+40Strong

Browser credential and cookie files

Refers to the files where browsers save passwords and cookies.

LAUNCHER+30Strong

Launcher account files

Refers to the launcher's account and profile files, such as launcher_accounts.json.

WALLET+30Strong

Crypto wallet references

Refers to crypto wallets: wallet.dat, MetaMask, Exodus, Electrum.

DPAPI+25Strong

Windows DPAPI decryption

Calls the Windows function that unlocks secrets saved by browsers and Discord.

KEYLOG+30Strong

Global keyboard hook library

Contains a library able to record the keys you type in any program, not only in the game.

ROBOT+20Signal

Screen capture and input control

Uses java.awt.Robot: it can take screenshots and move the mouse or press keys.

CLIP+10Signal

Accesses the system clipboard

Common for copy buttons. Stealers use it to read what you copied or to swap a wallet address.

IPLOOKUP+10Signal

Looks up your public IP address

Asks an online service for the computer's public IP, something stealers add to what they send.

Sending data out

Where stolen data could go.

WEBHOOK+45Strong

Discord webhook URL

Contains the address of a Discord webhook, the most common way for a stealer to send what it took to its author.

TELEGRAM+30Strong

Telegram bot API

Contains the address of the Telegram bot API, another common channel for stolen data.

BADHOST+20Signal

Paste, tunnel, file-drop or logger host

Points to a site often used to host payloads or collect data: paste sites, tunnels, file sharing, IP loggers.

IPURL+25Signal

Web address with a public IP

A web address written as a public IP number instead of a domain name.

NET+5Signal

Uses network functions

Most mods that check for updates or load skins do. Harmless alone.

Running programs and code

Ways to run something outside the mod itself.

EXEC+25Signal

Can start programs

Can start programs on your computer. Some normal mods do it, for example to open a folder or the browser.

SHELL+20Signal

Shell commands

Contains system shell commands, or names of Windows tools that malware often abuses.

REFEXEC+20Signal

Starts programs through reflection

Reaches the Java classes that start programs by name, which hides them from EXEC.

SCRIPTJAVA+25Strong

Script that runs programs

A script in the pack (KubeJS and similar) reaches Java code that starts programs or loads classes.

PERSIST+30Strong

Starts with the system

Sets something to start with the computer: the Windows Run key or Startup folder, scheduled tasks, cron, macOS launch agents.

DYNLOAD+20Signal

Loads classes at runtime

Defines classes from bytes or web addresses while running. Common in libraries; dangerous when the bytes come from the network.

AGENT+15Signal

Java agent

Declares a Java agent, which can rewrite other classes as they load.

WINAPI+15Signal

Calls Windows functions directly

Calls Windows functions through raw native pointers (LWJGL or JNA), outside Java's own APIs.

NATIVE+8Signal

Loads native libraries

Loads machine code, which the analysis cannot read. Common in rendering, audio and compression mods.

MAKEEXEC+4Signal

Marks files as executable

Gives files permission to run as programs.

REFLECT+5Signal

Reflection

Calls methods by name (Class.forName + Method.invoke). Very common in normal mods.

Chains

Two behaviours together in the same class. A chain says much more than either one alone.

CHAINSTEAL+50Strong

Credentials and network together

The same class reads the session token or credential files and uses the network: the shape of an account stealer.

CHAINDROP+40Strong

Download and run

The same class downloads code and then loads or runs it. Some real updaters and installers do it too: see the examples below.

CHAINUPDATE+15Signal

Self-updater shape

Downloads a jar, checks its checksum and starts it with java -jar. Usually an updater, so it counts as a signal.

CHAINLOAD+15Signal

Loads code from the network

Loads classes downloaded from the network. That code is not in the file, so the file is marked "cannot be judged".

Deep analysis (desktop app)

Found by the bytecode analysis of the desktop app, which follows calls between classes and rebuilds hidden strings.

DEOBF+20Strong

Hidden indicator

A webhook, a Telegram address or a shell command appears only in strings rebuilt at runtime: someone hid it on purpose.

TOKENEXFIL+40Strong

Credentials sent out

Token or credential access and the network within two calls of each other, even across classes.

DROPCHAIN+30Strong

Download and run across classes

A downloaded file is written and started within two calls of each other, even across classes.

EARLYRUN+15Strong

Runs at startup

Something the game runs as soon as it loads the mod (an entrypoint) reaches credential access or a download-and-run path.

REFTARGET+20Strong

Reflection to a sensitive target

Reflection resolves to the session token, or to the program-starting classes through a rebuilt name.

Hidden content

Things inside the jar that are not what they look like.

B64PAYLOAD+35Strong

Payload hidden in Base64

An executable, a class or an archive stored as Base64 text.

ENCODED+15Strong

Indicator hidden in Base64

A suspicious string, such as a webhook or an IP address, encoded in Base64.

HIDBIN+35Strong

Disguised executable

Executable bytes inside the jar under another extension.

HIDCLASS+25Strong

Disguised class

Java class bytes inside a file that does not end in .class.

LIBTAMPER+45Strong

Tampered library

A library bundled in the mod differs from its published build: files were added or changed.

BINEXT+30Signal

Executable or script in the jar

An .exe, .bat, .cmd, .ps1, .vbs, .scr, .msi or .com file inside the jar.

HIDZIP+20Signal

Hidden archive

A zip or jar inside the jar under another extension.

NESTJAR+20Signal

Nested jar in an unusual place

A jar inside the jar, outside the folders loaders use for bundled libraries.

NATEXT+12Signal

Native library in the jar

A .dll, .so, .dylib or .jnilib file inside the jar.

B64BLOB+10Signal

Long Base64 strings

Base64-like strings of 300 characters or more. Often images or fonts, sometimes a hidden payload.

OBFUSC+10Signal

Obfuscated

Most classes have 1 or 2 character names. Some normal mods are obfuscated too.

BADCLASS+10Signal

Unreadable classes

Class files that cannot be read: encrypted or corrupt. Many of them make the file "cannot be judged".

Files in the pack

Found while walking the modpack itself, outside the jars.

DISGUISED+45Strong

Disguised executable in the pack

An executable with the extension of another kind of file.

EXECFILE+30Strong

Executable or script in the pack

An executable or script file in the pack.

DISGUISEDZIP+30Strong

Disguised archive in the pack

A zip or jar with the extension of another kind of file.

LOOSECLASS+20Strong

Disguised class in the pack

Java class bytes in a file that pretends to be something else.

NATIVEFILE+12Strong

Native library in the pack

A native library lying loose in the pack.

JAROUT+10Strong

Jar outside mods/

A jar outside mods/, libraries/, versions/ and runtime/, where the game does not load it as a mod.

CORRUPT+20Signal

Unreadable archive

The archive cannot be opened. If it is really another format, such as a RAR renamed .zip, the file is "cannot be judged".

NOMETA+5Signal

Not a loadable mod

The jar or zip has no Fabric, Quilt, Forge or NeoForge metadata. Normal for resource packs.

Modpack index (.mrpack)

Problems in modrinth.index.json, the list of files an .mrpack downloads.

INDEXPATH+70Strong

Path traversal

A path in the index points outside the instance folder, so a download could overwrite files elsewhere. Checked on verified files too.

HASHCONFLICT+60Strong

Conflicting hashes

The sha1 and the sha512 in the index point to two different files.

HASHMISMATCH+50Strong

Download does not match

A downloaded file does not match the hash written in the index.

BADDOWNLOAD+30Strong

Unsafe download address

A download address is not https, or not on the hosts Modrinth packs may use.

BADINDEX+20Strong

Malformed index

modrinth.index.json has a malformed entry.

BADHASH+10Strong

Missing hashes

An index entry has missing or invalid hashes.

The scan itself

SCANERROR+15Strong

Not analysed

The file could not be analysed, so its result is incomplete. Never read it as clean.
